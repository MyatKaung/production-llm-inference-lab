Production LLM Inference Lab — guided course

This is a practical course, not a reading list. Each lesson has three parts: understand one idea, run or modify real code, then verify one observable result. Do not skip a practical check just because the explanation makes sense.

Follow this order

  1. Week 1.1 — Start the baseline notebook
  2. Week 1.2 — Chat templates and tokens
  3. Week 1.3 — Prefill and decode
  4. Week 1.4 — Non-streaming generation
  5. Week 1.5 — Streaming, TTFT, and inter-token latency
  6. Week 1.6 — Five-run benchmark and evidence
  7. Week 1.7 — HTTP server and endpoints
  8. Week 2.1 — Gateway boundary
  9. Week 2.2 — Fake backend tests
  10. Week 2.3 — Contracts and backend adapter
  11. Week 2.4 — Real HTTP backend integration

What “complete” means

A lesson is complete only when you have run its task, seen the stated output, and answered its check in your own words. The notebooks are the source of truth for Week 1:

  • week-01-baseline-server/practical-baseline.ipynb
  • week-01-baseline-server/streaming-and-missing-metrics.ipynb

Week 1 teaches one local model path. Week 2 wraps the same path in a gateway. We do not introduce batching, vLLM, or Kubernetes until these steps are understood and verified.
