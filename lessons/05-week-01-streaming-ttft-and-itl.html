Worked example

started = time.perf_counter()
thread = threading.Thread(target=model.generate, kwargs=kwargs)
thread.start()
for event in streamer:
    token_events.append(event)  # ("token", token_id, timestamp)

The first event timestamp minus started is TTFT. The gaps between later events are inter-token latency (ITL).

TTFT = first_token_time - request_start
ITL[0] = second_token_time - first_token_time
total latency = generation_finished - request_start
